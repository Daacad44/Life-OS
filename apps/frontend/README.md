# @life-os/frontend

React + TypeScript frontend for Life OS (Vite, Tailwind CSS v4, shadcn/ui).

```bash
npm run dev      # http://localhost:5173
npm run build
npm run lint
```

See the repo root [`README.md`](../../README.md) and [`docs/Life-OS-Blueprint`](../../docs/Life-OS-Blueprint/Life-OS-Blueprint/00-README.md) for the full blueprint.
